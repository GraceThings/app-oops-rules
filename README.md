# App Oops Community Rules (`GraceThings/app-oops-rules`)

Community-maintained AppOps permission presets for **App Oops**.

## Subscription URLs

Users can subscribe inside **App Oops -> Rules -> Community Rules -> `+` (Add Subscription)** using any of the following links:

- **GitHub Repository / Shorthand**: `https://github.com/GraceThings/app-oops-rules` (or `GraceThings/app-oops-rules`)
- **GitHub Raw**: `https://raw.githubusercontent.com/GraceThings/app-oops-rules/main/index.json`
- **jsDelivr CDN**: `https://cdn.jsdelivr.net/gh/GraceThings/app-oops-rules@main/index.json`
- **Gitee Mirror**: `https://gitee.com/GraceThings/app-oops-rules`

## Repository Structure

```text
app-oops-rules/
├── index.json                           # Auto-generated by GitHub Actions (do NOT edit manually)
├── rules/
│   └── <packageName>/
│       └── <rule-id>.json               # One rule per JSON file to avoid PR merge conflicts
└── .github/
    ├── ISSUE_TEMPLATE/submit_rule.yml   # Structured submission form pre-filled by App Oops
    └── workflows/
        ├── validate-pr.yml              # Validates JSON schema & AppOps whitelist on PRs
        ├── issue-to-pr.yml              # Converts rule-submission Issues into PRs automatically
        └── build-index-and-sync.yml     # Builds index.json on main and mirrors to Gitee
```

## Rule JSON Schema

```json
{
  "id": "anti-shake-clipboard",
  "packageName": "com.taobao.taobao",
  "appName": "淘宝",
  "title": "拦截摇一摇广告与读剪贴板",
  "description": "禁用加速度计/陀螺仪并拦截读取剪贴板，保留写入剪贴板。",
  "author": "GraceThings",
  "level": "balanced",
  "recommended": true,
  "updatedAt": "2026-11-12",
  "ops": {
    "BODY_SENSORS": "IGNORE",
    "HIGH_SAMPLING_RATE_SENSORS": "IGNORE",
    "ACTIVITY_RECOGNITION": "IGNORE",
    "READ_CLIPBOARD": "IGNORE"
  }
}
```

### Allowed `level` Values
- `gentle`
- `balanced`
- `strict`

### Allowed `ops` Keys & Modes
- **Keys**: `BODY_SENSORS`, `BODY_SENSORS_BACKGROUND`, `HIGH_SAMPLING_RATE_SENSORS`, `ACTIVITY_RECOGNITION`, `READ_CLIPBOARD`, `WRITE_CLIPBOARD`, `QUERY_ALL_PACKAGES`, `GET_USAGE_STATS`, `RUN_IN_BACKGROUND`, `RUN_ANY_IN_BACKGROUND`, `WAKE_LOCK`, `SYSTEM_ALERT_WINDOW`, `WRITE_SETTINGS`, `ACCESS_NOTIFICATIONS`
- **Modes**: `ALLOW`, `IGNORE`, `DENY`, `DEFAULT`

## Setting Up Gitee Mirror Sync

1. Create an empty repository named `app-oops-rules` under `https://gitee.com/GraceThings`.
2. Generate a Personal Access Token (私人令牌) in Gitee Settings with `projects` push permission.
3. Add repository secret `GITEE_TOKEN` in **GitHub Repository Settings -> Secrets and variables -> Actions**.
4. In GitHub Settings -> Actions -> General -> Workflow permissions, enable **Read and write permissions** and check **Allow GitHub Actions to create and approve pull requests**.
5. Push these template files to `main` on GitHub; Actions will automatically generate `index.json` and mirror everything to Gitee.
